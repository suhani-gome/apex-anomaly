## Current Project Direction

The project will be developed as an AI-assisted healthcare care-navigation system.

The system will focus on healthcare information and navigation rather than medical diagnosis or treatment prescription.

## Provisional Technology Direction

- Frontend: React / Next.js
- Backend: Python + FastAPI
- Database: PostgreSQL
- AI/RAG: To be finalized according to project requirements
